# Persian Font Pack — Frontend

84 Persian fonts extracted from `Fonts.rar` (Google Drive).

- Served at `/fonts/persian-pack/<file>`
- Defined in `frontend/src/persian-fonts.css` (auto-imported via `style.css`)
- Manifest: `manifest.json` (84 entries)

Use `font-family: '<FontName>'` — نام هر فونت = نام فایل بدون پسوند (مثلاً `B Yekan`, `IranNastaliq`, `0 Titr Bold`).

See `assets/fonts/README.md` for full details and licensing notes.
